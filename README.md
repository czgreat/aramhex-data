# AramHex 数据：海克斯大乱斗统计

英雄联盟国服「海克斯大乱斗」（ARAM: Mayhem）的对局统计：**英雄胜率**、**英雄 × 海克斯胜率**，以及按分数段（娱乐 / 中分 / 高分 / 顶尖）拆开的同样两项。按游戏版本存放，常规规则和活动规则（如首次必棱彩）分开统计。

- 只有统计结果，不含玩家 ID、名字、对局编号、原始对局或个人分数。
- 国服各大区（艾欧尼亚、黑色玫瑰、联盟一区至五区）合在一起，不分区；每份数据覆盖哪些区见下表。
- 协议 [CC BY-NC 4.0](LICENSE)：可以自由使用、转载、改编，需注明来源，不能商用。
- 写程序或让 AI 读数据，请先看 [AGENTS.md](AGENTS.md)。
- 配套的桌面助手：[czgreat/aramhex](https://github.com/czgreat/aramhex)（安装版和便携版都内置发布时最新的数据）。
- 在线查询（网页，按英雄或按海克斯）：[aramhex.com/data](https://aramhex.com/data/)。某个英雄每个海克斯的胜率打开 `https://aramhex.com/data/hero/英雄名/`（如 [亚索](https://aramhex.com/data/hero/%E4%BA%9A%E7%B4%A2/)），某个海克斯在每个英雄上的胜率打开 `https://aramhex.com/data/augment/海克斯名/`（如 [秘术冲拳](https://aramhex.com/data/augment/%E7%A7%98%E6%9C%AF%E5%86%B2%E6%8B%B3/)）。

## 每份数据里有什么

```
patches/<版本>/<规则>/
  meta.json                  口径：样本时间、对局数（采到 / 有效 / 排除）、有效对局的标准、局限、文件 SHA-256
  heroes.json / heroes.csv   英雄胜率
  hero_augments.json / .csv  英雄 × 海克斯胜率
  augments.json              海克斯中文名和稀有度
  hero_spells.json          英雄 × 召唤师技能组合（16.21 起；部分版本另有 .csv）
  bands/<casual|mid|high|top>/  娱乐 / 中分 / 高分 / 顶尖局的 heroes 和 hero_augments（有分段数据时）
```

CSV 和 JSON 内容一样，CSV 多带中文名和稀有度，UTF-8 带 BOM，可以直接用 Excel 打开。

**heroes**：英雄 ID → `name` 英雄名、`title` 称号、`games` 出场次数、`wins` 胜场、`win_rate` 胜率、`pick_rate` 出场占比（占所有英雄出场的比例）、`rank` 胜率名次。

**hero_augments**：英雄 ID → 海克斯 ID → `games`、`wins`、`win_rate`、`low_sample`（样本少，胜率波动大）。

## 统计口径

- **有效对局**：对局时长不少于 4 分钟（240 秒）、10 名玩家齐全且正好 5 胜 5 负、正常结束（GameComplete）；重开、提前解散、数据不全的对局不计。「采到的对局」是统计时间段内采集到的全部对局，「有效对局」是其中参与统计的部分。
- 只统计我们采集到的对局，不是全服数据。
- 海克斯按对局结束时持有的计算：同一玩家的六个海克斯槽位去重，任意槽位持有即计入。
- 持有某个海克斯和赢下对局是相关关系，不代表拿了它就会赢。
- 各大区的样本直接合在一起计算，没有按区加权；每份数据覆盖哪些区见 regions。
- 样本少的组合（low_sample 为 true，或局数很少）胜率波动大，请谨慎参考。
- **分数段**：分段按玩家在所在区的「同局关系显示分」划分（根据同局胜负关系推算，各区分别计算），不是官方段位。娱乐：区内多数玩家（约 64%）；中分：前 5–36%；前 5%：显示分 2400 以上（bands/high 和 bands/top 相同）。16.21 起改按各区玩家评分的区内分位：娱乐 >36%、中分 5%–36%、前 5% ≤5%，没有评分的玩家只进入全体。分段数据的样本时间和全体数据不同，见各自 `meta.json` 的 `bands`。
- **稀有度**：按腾讯公开资料，和拳头官方资料（CommunityDragon）逐个核对，不一致时以游戏里的卡框为准更正。现在只有「连锁反应」（2078）一个：腾讯标棱彩，游戏里和拳头资料都是黄金。2026-10-31 起所有目录都已改为黄金，`data-v1`～`data-v10` 这些 tag 里仍是棱彩。
- 被剔除的海克斯写在 `meta.json` 的 `excluded_augments`。例如 16.20 的「尊我为王」：完成任务就会被换成新海克斯，对局结束时还持有它的都是没完成任务的人，胜率会系统性偏低。
